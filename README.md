# The Algorithm of Speed Dating: Identifying the Key Factors of a Successful Match

This project explores the psychology and statistics behind speed dating success. Conducted as a **team research project**, we used statistical analysis in R to determine which factors most significantly influence romantic matches during speed dating events.

##  Team Collaboration

Although this was a **group project**, I actively contributed to **every phase** — from research and data cleaning to presentation and analysis. My primary technical responsibility was performing the **Principal Component Analysis (PCA)** to identify the most impactful traits in a successful match.

##  My Contribution: PCA in R

I used Principal Component Analysis to reduce the dimensionality of the data and uncover which personality traits play the biggest role in forming romantic matches. Key findings from my PCA work include:

- **"Fun" and "Ambition"** were the top traits influencing a successful connection.
- **Attractiveness ranked fourth**, challenging the assumption that looks dominate first impressions.
- These insights suggest speed dating success is more tied to personality than physical appearance.
- My results support creating a **pre-dating questionnaire** focused on personality traits to improve match outcomes.

##  Techniques Used

- Principal Component Analysis (PCA)
- Canonical Correlation Analysis (CCA)
- Correspondence Analysis
- Ridge Regression

##  Dataset Notes

The dataset, collected by Columbia University between 2002–2004, included significant missing data (75% incomplete). This limited the variables we could use and affected the generalizability of the findings to modern dating contexts.

##  Future Work

We recommend repeating this study with:
- Updated and more complete datasets
- Broader, non-college-based demographics
- Consideration of online dating trends and post-COVID dating norms
